# Три дверцы

Игра на чтение и скорочтение для детей-билингвов, которые читают на английском, русском и украинском и путают языки.

У каждого языка свой цвет и свой герой, и каждый герой говорит только на своём языке:

- синяя сова Олли — English;
- красный лис Рыжик — русский;
- жёлтый подсолнух Сонько — українська.

## Что внутри

- Анкета для взрослого и проверка примерно на 5 минут. Проверка показывает уровень по каждому языку, путает ли ребёнок языки и на каких буквах-двойниках ошибается (P/Р, H/Н, и/і).
- Личный план из 12 занятий по карте. Больше времени получает язык, который даётся труднее, а уровни растут сами.
- Для тех, кто только учит буквы, есть уровень «Учу буквы» с тремя режимами: «Знакомлюсь с буквами» (буква, опорное слово и картинка, герой называет букву), «Первый звук» (картинка и слово на слух, нужно выбрать первую букву) и «Собери слово», а также «Слияние»: буква катится к гласной (М + А = МА), потом слова читаются по слогам (ЛУ-НА); в английском так собираются короткие слова (c-a-t). Буквы идут в порядке обучения, по три за занятие. Среди вариантов всегда есть буква из чужого алфавита.
- Для читающих четыре режима: «Прочитай и найди», «Вспышка» (скорочтение), «Чьё слово?», «Буквы по порядку».
- Наклейки, серии правильных ответов и озвучка: 481 слово и по 20 реплик на героя.

Всё работает в одном файле `index.html`, сборка не нужна. Прогресс хранится в браузере (localStorage).

## Файлы

| Путь | Что это |
|---|---|
| `index.html` | игра |
| `art/` | герои, карта и наклейки (webp) |
| `voice/` | голоса: один аудиоспрайт на язык и `index.json` с тайм-кодами |
| `make-art.py` | вырезает фон у картинок из `art-src/` (оригиналы в git не лежат, id заданий Higgsfield — в `art-src/jobs.json`) |
| `make-voice.py` | режет записи слов по тишине и собирает спрайты (тексты — в `voice-src/`) |
| `index-v2.html` | прошлая версия без плана и голосов |

## Запуск локально

```
python3 -m http.server 4302
```

Потом откройте http://localhost:4302. Картинки и голоса Higgsfield (nano banana, ElevenLabs).
